# guiClaw Website

A modern, responsive landing page for guiClaw - the custom OpenClaw Web GUI.

## Features

- **Modern Design**: Clean, professional design with gradient backgrounds
- **Responsive**: Works on desktop, tablet, and mobile devices
- **Interactive Elements**: Hover effects, animations, and demo buttons
- **Quick Start Guide**: Clear installation and setup instructions
- **Feature Showcase**: Highlights all key guiClaw features
- **Version Badge**: Shows current version (v0.35)

## Quick Start

1. **Open the website**:
   ```bash
   open index.html
   ```

2. **Or serve it locally**:
   ```bash
   python3 -m http.server 8080
   # Then visit http://localhost:8080
   ```

3. **Or use with guiClaw**:
   Replace the existing `index.html` in your guiClaw folder:
   ```bash
   cp index.html ~/Desktop/guiClaw/
   ```

## Installation Instructions

The website includes step-by-step installation instructions:

1. Start OpenClaw Gateway
2. Enable HTTP API
3. Run guiClaw proxy server
4. Open in browser

## Customization

You can customize the website by editing:

- **Colors**: Update CSS variables in the `<style>` section
- **Text**: Modify the content in the HTML
- **Features**: Add/remove feature cards
- **Links**: Update the GitHub link and demo button

## Technical Details

- **Single File**: All HTML, CSS, and JavaScript in one file
- **No Dependencies**: Pure vanilla JavaScript and CSS
- **Responsive**: Uses CSS Grid and Flexbox
- **Animations**: CSS keyframe animations for smooth transitions
