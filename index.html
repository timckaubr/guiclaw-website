🦀 guiClaw
Custom OpenClaw Web GUI

Welcome to guiClaw

A beautiful, modern web interface for OpenClaw - your personal AI assistant running locally on your machine.

🌐

Web-Based Interface

Access OpenClaw from any browser on your local network. No terminal required!

💬

Real-time Chat

Chat with your AI assistant in a modern, responsive chat interface.

📁

File Upload

Upload files directly through the web interface for analysis.

🔄

Model Switching

Switch between different AI models with a single click.

📱

WhatsApp Integration

Connect and manage WhatsApp channels directly from the GUI.

⚙️

Easy Configuration

View and modify OpenClaw settings through a user-friendly interface.

🚀 Quick Start

1
Start OpenClaw
openclaw gateway start
2
Enable HTTP API
openclaw config set gateway.http.endpoints.responses.enabled true
3
Run guiClaw
node ~/Desktop/guiClaw/proxy.js
4
Open Browser
http://localhost:8000
